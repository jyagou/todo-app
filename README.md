# 🌿 Todo List

A clean, dark-themed to-do app built with plain HTML, CSS and JavaScript.

**[👉 Live Demo](https://jyagou.github.io/todo-app/)**


## Features

- Add, edit and delete tasks
- Categories: School, Health & Fitness, Personal, Others
- Due dates with friendly labels (Today, Tomorrow, Yesterday)
- Filters: All, Active and Completed, with live counts
- Sort by due date, newest, or name
- Tasks are saved in the browser with localStorage
- Custom checkboxes, icons and a night-scene header

## Built with

- HTML5
- CSS3 (Flexbox, custom checkboxes, SVG art)
- Vanilla JavaScript (no frameworks)

## What I learned

- Building UI from a design mockup
- Keeping app data in a list and redrawing the page from it
- Saving data with localStorage
- Using Git and GitHub, and deploying with GitHub Pages
